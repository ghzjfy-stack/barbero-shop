## If Boost is still blocked

For minoxidil / hair products, Instagram **Boost** is often permanently unavailable — policy, not the video file.

### Do this instead (Ads Manager)

1. Facebook Ads Manager (business.facebook.com/adsmanager)
2. Create → Ad → objective **Traffic** or **Sales** (not “Boost post” from the app)
3. If Meta asks for a special category → **Health / wellness** (or Pharmaceuticals if shown)
4. Creative = this reel upload as Advantage+ / manual placement Reels + Stories
5. Destination = Instagram profile link / site product URL

### Checklist on the account

- Instagram is **Professional** (Business or Creator)
- Linked **Facebook Page**
- Ads account not disabled / payment method ok
- You are boosting the **new** cans reel, not an old Rogaine-carton post

Creative alone cannot unlock Boost if the category is blocked.
