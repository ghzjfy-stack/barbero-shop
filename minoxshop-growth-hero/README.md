# MinoxShop — Growth Scrubber Hero

Interactive before/after hero: drag right by months and the real scalp photo fills in.

## Assets
- `assets/ba-before.jpg` / `assets/ba-after.jpg` — cropped from the live site photo `results-4-months.png` (not AI).
- Months follow a realistic manufacturer-style pace (clearer around month 4).

## Preview
```bash
cd minoxshop-growth-hero && python3 -m http.server 8765
```

## Integrate into minox-shop.co.il
Drop this folder’s markup/CSS/JS into the MinoxShop homepage hero (replace the points/SALE banner). CTA currently points to `https://www.minox-shop.co.il/#pricing`.
